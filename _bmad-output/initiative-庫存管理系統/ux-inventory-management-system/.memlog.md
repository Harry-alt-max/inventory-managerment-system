- (decision) UI 系統： shadcn/ui + Tailwind CSS（React 19 相容、token 可程式化、元件原始碼在專案內）；語意 token 由 DESIGN.md 定義，元件沿用 shadcn 預設
- (decision) 語系： 完整雙語 — 繁體中文（zh-TW）為預設、英文（en-US）為次要；介面文字、錯誤訊息、日期、數字與金額格式一律隨語系切換；字串一律抽到 message catalog，元件內不得硬寫字
- (decision) 色彩模式： 淺色與深色兩套，同一組語意 token 兩種取值；預設跟隨作業系統，可在設定中固定
- (decision) 使用情境： 桌機優先、緊湊資訊密度（後台表格工作型），小螢幕不特別最佳化；欄寬、列高、間距取緊湊級
- (decision) 首頁與導覽： 登入後依角色分流工作台 — 倉管→庫存現況、採購→待補貨清單、銷售→開單入口、會計→毛利查核；四角色共用同一組側邊導覽與全域商品搜尋
- (decision) 關鍵畫面 mock 四張： 登入頁、庫存查詢清單、銷貨單（即時毛利）、待補貨清單
- (decision) 語音與語氣： 內部工作工具，簡潔、專業、單一任務一頁；動詞開頭的按鈕（入庫、領用、移轉、建立調貨單）；錯誤訊息說明發生什麼與如何修正，不出現代碼或堆疊；數字與金額一律顯示單位與千分位；不使用驚嘆號與行銷語氣
- (decision) 空狀態與載入： 空狀態說明這個頁面能做什麼並給出下一步動作按鈕；載入中用骨架而非轉圈；任何破壞性操作（取消銷貨、停用帳號）需二次確認並說明不可復原
- (assumption) 無障礙最低標準： WCAG 2.1 AA 對比、完整鍵盤操作、表格與表單有可讀標籤與焦點可見；實作細節於 EXPERIENCE.md 的 Accessibility Floor
