# 庫存異動、跨倉調度與補貨水位

## Description

入庫、領用、同倉移轉、跨倉調貨都留下可追溯的異動紀錄（操作人員沿用 E1 的登入者機制、單價取自 E2 的採購批次、交易與僅追加規則沿用 E1 的守衛規則基線），並提供可定位位置與庫存數量的商品查詢（R5）與低於水位的待補貨清單。

## Outcome

倉管的每一次入庫、領用、移轉、調貨都留下可追溯的異動，採購看得到哪些商品低於水位要補貨（initiator 的 R5、R6、R8、R11～R14）。

## Constraints

- 入庫必須指定批次；採購單價取自該批次，入庫畫面不另行輸入單價。
- 領用不得超過可用數量；領用用途只有「客戶寄貨」與「臨時出貨」，**不得帶「銷貨」用途**（銷售扣減一律走 E4 的銷貨單）。
- 位置移轉限於同一倉庫；跨倉庫變動必須對應一張調貨單。
- 調貨單由**銷售**建立，**倉管唯讀可見**但不可建立（PRD FR-2 權限矩陣，2026-10-21 裁決）。
- 庫存數量不得為負；造成庫存變動的寫入以交易執行，任一步失敗整筆回滾。
- 異動紀錄僅追加，不可修改或刪除；每筆含商品、操作人員、異動數量正負號、日期、用途與批次。
- 移轉與調貨各產生移出、移入兩筆異動（每個變動行為一筆）。

## Done when

1. 倉管入庫後，該位置該商品的庫存增加相同數量，並產生一筆含批次與操作人員的入庫異動。
2. 領用超出可用數量時被拒絕並顯示可用數量；成功領用產生一筆含用途的異動且不計毛利。
3. 同倉移轉後總庫存不變，移出位置減少、移入位置增加，且各產生一筆異動。
4. 跨倉調貨產生移出與移入兩筆異動，兩筆都可對應回同一張調貨單，總庫存不變。
5. 依名稱查商品可看到各位置的庫存數量與所在倉庫，結果數量與各位置加總一致。
6. 設定水位後，低於水位的商品出現在待補貨清單（含現有庫存、水位、缺口、供應商）；補貨至水位（含）以上後自動離開清單。
7. 庫存數量不會變負；交易中途失敗時整筆回滾；任何角色的異動紀錄都無法修改或刪除。

## Boundaries

- 本 epic 屬於：庫存現況（商品 × 位置 × 數量）、入庫、領用、同倉移轉、跨倉調貨單、庫存異動紀錄、補貨水位與待補貨清單、商品定位查詢。
- 不屬於本 epic：商品與批次主檔（E2）、銷貨與毛利（E4，只呼叫本 epic 的扣減機制）、成本彙總與 FIFO 結算（E4 使用，本 epic 只提供批次原始資料）。
- 不可改變：移轉限同倉、跨倉必須有調貨單、領用不得帶銷貨用途——這三條是 E1 守衛規則基線的行為契約。
